# Ars Taty — Сайт-портфолио тату-мастера

Многостраничный адаптивный веб-сайт для частной тату-студии с акцентом на монохромный минимализм, строгую типографику, быстродействие и защиту персональных данных.

## 🚀 Ключевые особенности

* **ЧПУ-навигация:** Архитектура построена на изолированных директориях с собственными файлами `index.html`, что обеспечивает чистые URL без расширения `.html` в адресной строке (`/works/`, `/prices/`, `/about/`, `/articles/first-tattoo/`).
* **Just-In-Time сборка контактов:** Номер телефона не хранится в DOM-дереве в открытом виде. Значения фрагментированы в Base64 (`data-p1`, `data-p2`) и монтируются в протокол `tel:` только при реальном физическом взаимодействии пользователя (`pointerenter`, `touchstart`, `focus`), блокируя автоматические парсеры.
* **Семантика HTML5:** Логичная структура документа с применением `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<blockquote>`, `<cite>` и `<footer>`.
* **Адаптивность и мобильный UX:** Полноэкранное всплывающее меню, оптимизация тач-событий под iOS Safari, корректная изоляция состояний наведения через `@media (hover: hover)`.
* **Zero Dependencies:** Чистый нативный стек (Vanilla JS, кастомный CSS) без внешних фреймворков и библиотек для максимальной скорости загрузки.

## 🛠 Стек технологий

* **HTML5** (семантическая разметка, data-атрибуты)
* **CSS3** (Flexbox, CSS Grid, Media Queries, плавные переходы)
* **JavaScript (ES6+)** (Vanilla JS, делегирование событий, Base64-декодирование)

## 🌐 Развертывание на GitHub Pages

1. Загрузите проект в репозиторий на GitHub.
2. Откройте **Settings** -> **Pages**.
3. В графе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` (или `master`), каталог `/ (root)` и нажмите **Save**.
